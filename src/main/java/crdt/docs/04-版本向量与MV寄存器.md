# 第 4 步：`VersionVector` + `MVRegister` —— 并发写两个都留

**目标**：同一个 key 被两台离线设备改成不同值，**两个值都保留**，把冲突抛给用户。

**大白话**：要判断两个写是不是"真并发"，需要**因果历史**。版本向量就是"每个副本写过几次"的计数器数组：

```
版本向量   A: {A:2, B:1}      ← A 自己写了 2 次，见过 B 的 1 次
           B: {A:1, B:3}
比较：互相都有对方没有的 → 真并发（concurrent）
      一方每个分量都 >= 另一方 → 后者被因果覆盖，可以安全丢弃
```

- `{A:2}` vs `{A:1}` → 前者支配后者，丢弃旧值
- `{A:2,B:1}` vs `{A:1,B:3}` → 互相都不支配对方 → **并发，两个都留**

## 你要写的 API

```java
public final class VersionVector {
    public static VersionVector empty();
    public static VersionVector of(Map<String,Long> counters);  // 直接构造（第 9 步算稳定前沿要用）
    public long get(String replicaId);                    // 未知返回 0
    public VersionVector increment(String replicaId);
    public VersionVector merge(VersionVector other);      // 逐 key 取 max
    public boolean greaterOrEqual(VersionVector other);   // 逐分量 >=
    public boolean dominates(VersionVector other);        // 严格大于
    public boolean isConcurrent(VersionVector other);     // 互相都不 >=
    public Map<String,Long> asMap();
}

public final class MVRegister<T> implements CvRDT<MVRegister<T>> {
    public static <T> MVRegister<T> empty();
    public MVRegister<T> assign(T value, String replicaId);
    public Set<T> values();            // size() > 1 表示存在并发冲突
    public int size();
    public boolean isEmpty();
    public VersionVector version();
    public MVRegister<T> merge(MVRegister<T> other);
}
```

## 硬性不变量（本步最难，重点看）

内部状态是一组 `(版本向量, 值)` 的**规范集合**，必须始终满足：

- [ ] **不存在被支配的项**：如果 `e2.vv` 严格支配 `e1.vv`，`e1` 必须被剔除（它的写因果上已被覆盖）
- [ ] **不存在完全重复的项**：`(vv, value)` 唯一
- [ ] `assign` = 先 `vv' = version().increment(replicaId)`，丢弃所有被 `vv'` 支配的旧项，再加入 `(vv', value)` → 结果必然是单值
- [ ] `merge` = 两边取并集 → 剔除被严格支配的 → 去重。**"剔除"这一步最容易写漏，写漏了就会残留早该被覆盖的旧值**
- [ ] `version()` = 所有项版本向量的 join

## 破坏性实验

在 `merge` 里去掉"剔除被支配项"那一步（只做并集 + 去重）。跑 `MVRegisterTest` 里"因果写应只剩一个值"的用例，你会看到 `size()` 变成 2——**旧值没被清掉**。这说明：光有版本向量还不够，**必须真的用它做剪枝**。

## 自检问答

1. 版本向量和 Lamport 时钟的本质区别？（答：Lamport 是**全序**（任意两个都能比大小，但会武断排序）；版本向量是**偏序**（能识别"不可比" = 真并发））
2. MVRegister 的代价？（答：因果元数据随副本数增长；冲突值要上层解决，不能自动合并）
